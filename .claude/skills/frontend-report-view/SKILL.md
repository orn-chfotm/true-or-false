# frontend-report-view

제품의 핵심 산출물인 AE용 리포트 화면을 만드는 절차다.

근거: `.claude/rules/frontend/05-report-view.md`, `backend/03-report-snapshot.md`

## 절차

1. 서버 리포트 스냅샷 DTO를 그대로 렌더한다. 프론트에서 재집계하지 않는다.
2. 고정 섹션을 배치한다.
   - 핵심 요약, 설득력 점수, 찬반 비율, 논란 리스크 점수
   - 긍정/부정 근거, 대표 원문(익명·마스킹), 카피 수정 제안
   - **표본 신뢰 라벨**(분포·타깃 충족률·승인/제외 수)
   - **방법론 주석**(빠른 반응 스냅샷 안내)
3. 대중 판단과 AI 근거 검토를 분리해 표시한다. 무효 처리 통계도 함께 보여준다.
4. 제안서용 복사/공유(요약 복사, 공유 링크, 추후 PDF)를 붙인다.
5. `review_required` 상태 리포트는 전달·공유를 막는다.

## 체크리스트

- [ ] 신뢰 라벨·방법론 주석이 고정 섹션으로 항상 표시되는가?
- [ ] 대중 판단과 AI 검토가 분리 표시되는가?
- [ ] 대표 원문이 익명·마스킹 값만 쓰는가?
- [ ] "대표 표본/전국 여론" 같은 과장 카피가 없는가?
- [ ] 검수 전(`review_required`) 리포트의 공유·전달이 막히는가?

## 산출물

```md
## 리포트 화면

- 섹션 구성:
- 신뢰 라벨/방법론 위치:
- 대중 판단/AI 분리:
- 복사·공유:
- 전달 가드:
```
