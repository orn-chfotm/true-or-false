# 테스트 정책

이 문서는 테스트 실행·미실행·실패의 처리와 보고 기준을 정의한다.

# 연관 관계

- 오류 처리 참조: @.claude/rules/harness/09-error-handling.md

# [금지사항]

- 실패한 테스트는 숨기지 않는다.

# 기본 원칙

- 가능한 테스트는 실행한다.
- 실행하지 못한 테스트는 이유를 남긴다.
- 실패 원인이 작업 범위 밖이면 PL 또는 CTO에게 에스컬레이션한다.

# 보고 형식

```md
## 테스트 결과

- 실행한 테스트:
- 결과:
- 실패 항목:
- 실패 원인:
- 미실행 테스트:
- 미실행 사유:
```
