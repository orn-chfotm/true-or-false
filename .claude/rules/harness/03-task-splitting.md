# 작업 분리 기준

이 문서는 PA 작업을 나누는 조건, 작업 카드와 분리된 작업의 통합 기준을 정의한다.

# 연관 관계

- PL 역할 참조: @.claude/rules/harness/roles/03-pl.md
- PA 역할 참조: @.claude/rules/harness/roles/04-pa.md

# [금지사항]

## 작업 분리

다음 경우에는 여러 PA로 나누지 않는다.

- 같은 작은 파일을 동시에 수정한다.
- 작업 순서 의존성이 강하다.
- 설계가 확정되지 않았다.
- 승인되지 않은 기술 방향이 포함된다.
- 통합 비용이 실행 비용보다 크다.

## 통합과 정리

- PA는 현재 디렉토리로 직접 통합하거나 PL 검증 전 작업 영역을 정리하지 않는다.

# 분리 가능한 기준

다음 기준 중 하나 이상을 만족하면 분리할 수 있다.

- 파일 영역이 다르다.
- 기능 영역이 다르다.
- 문서 작성과 코드 구현이 분리된다.
- 테스트 작성과 구현이 분리된다.
- 조사, 설계, 실행, 검토가 독립적으로 진행될 수 있다.

# PA 작업 예시

```md
## PA 작업 분리

- PA-1: 공통 문서 초안 작성
- PA-2: 역할별 문서 작성
- PA-3: tool별 진입점 문서 작성
- PA-4: 전체 용어와 링크 검토
```

# 통합 기준

PL은 PA 결과를 통합할 때 다음을 확인한다.

- PA가 지정된 분리 작업 컨텍스트에서만 작업했는지 여부
- 용어 일관성
- 중복 규칙 여부
- 역할 경계 침범 여부
- 현재 디렉토리 통합 가능 여부
- 통합 후 검증 필요 항목
- 승인 게이트 누락 여부
- 지원 adapter에서 공통으로 해석 가능한지 여부

# 병렬 실행 리스크

여러 PA 작업은 속도를 높일 수 있지만 통합 리스크를 만든다.

PL은 병렬 실행 전에 다음을 확인한다.

- 같은 파일을 동시에 수정하지 않는가?
- 같은 용어를 서로 다르게 정의하지 않는가?
- 한 PA의 결과가 다른 PA의 전제 조건이 아닌가?
- 통합 책임자가 명확한가?
- PA별 분리 작업 컨텍스트와 현재 디렉토리 통합 기준이 명확한가?
- 실패한 PA 작업을 제외해도 나머지 결과를 사용할 수 있는가?

# 작업 카드 형식

PA 작업은 다음 형식으로 분리한다.

```md
## PA 작업 카드

- 작업 ID:
- 담당 역할:
- 작업 컨텍스트:
- 현재 디렉토리 통합 기준:
- 작업 실행 주제:
- 목표:
- 수정 가능 영역:
- 수정 금지 영역:
- 입력 문서:
- 읽기 대상 파일:
- 읽기 제한:
- 산출물:
- 검증 기준:
- PL에게 보고할 항목:
```

PL은 `PL에게 보고할 항목`에 최소한 다음 항목을 포함시킨다.

- 작업 실행 주제
- 작업 컨텍스트
- 현재 디렉토리 통합 기준
- 수정 파일
- 처리 결과
- 검증 결과
- 에러/불가 처리 내용
- 상위 단계 보고 필요 여부
- 절차 재진행 필요 여부

# 에스컬레이션 기준

PA는 작업 중 다음 상황을 발견하면 PL에게 올린다.

- 수정 가능 영역 밖의 변경이 필요하다.
- 수정 가능 영역 밖의 파일을 읽거나 분석해야 한다.
- 기술 방향이 CTO 검토와 다르다.
- 사용자 승인이 필요한 새 결정이 생긴다.
- 다른 PA 작업과 충돌한다.
- 에러 또는 불가 처리로 상위 단계 판단이 필요하다.
- 작업 컨텍스트와 현재 디렉토리 통합 기준이 불명확하다.

# 분리 작업 통합 기준

PA 작업은 멀티스레드별 분리 작업 컨텍스트에서 수행한다.

PL은 PA 작업을 나눌 때 작업 컨텍스트와 현재 디렉토리 통합 기준을 함께 지정한다.

PA는 분리 작업 컨텍스트에서 변경을 완료하고 결과를 보고한다.

PL은 PA 결과를 리뷰하고 검증한 뒤 PA 작업 결과를 현재 디렉토리에 통합한다.

PL은 통합 후 현재 디렉토리에서 통합 검증을 수행하고, 검증이 끝난 뒤 PA의 분리된 작업 영역을 정리한다.

# 파일 범위 제한

PL은 PA 작업을 나눌 때 읽기 대상과 수정 가능 영역을 함께 지정한다.

PA는 지정된 읽기 대상과 수정 가능 영역을 우선한다.

지정되지 않은 파일을 읽거나 수정해야 하면 PL에게 보고하고, 범위 밖 변경이면 사용자 확인을 받는다.
